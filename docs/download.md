## 从 PyPI 安装

```bash
pip install telepress
```

可选依赖以 extra 形式提供，具体名称见 [README 的「安装」一节](/README.md#安装)。

## 从源码安装

```bash
git clone https://github.com/redtidev1918/telepress.git
cd telepress
pip install -e .
```
